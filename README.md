# Environmental Robotics Data Service

A Linux-based service that accepts, stores, queries, and reports environmental sensor readings.

## Features

- REST API for stations, sensors, readings, and alerts.
- PostgreSQL database.
- Endpoints
- Input validation for units, ranges, timestamps, and missing fields.
- Docker Compose setup for local deployment.
- Unit and integration tests.
